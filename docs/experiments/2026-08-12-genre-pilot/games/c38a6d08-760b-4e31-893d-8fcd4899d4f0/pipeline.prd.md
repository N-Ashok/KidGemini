**Product Requirements Document: "CreatorVerse 3D" Game Builder**

**Concept:** CreatorVerse 3D is a web-based platform that empowers children aged 8-12 to design, build, and share their own 3D games using intuitive visual tools, inspired by their favorite game genres.

**Core Loop:**
1.  **Choose a Template:** Select a starting game type (e.g., racing, sports, adventure).
2.  **Build & Customize:** Place objects, paint terrain, add characters, and set basic behaviors.
3.  **Play & Test:** Instantly test creations to identify areas for improvement.
4.  **Share:** Publish games for friends and the CreatorVerse community to play.

**Win/Lose Condition:** (For games built within CreatorVerse) Varies based on the game template and creator's design. For example, a soccer game could have a win condition of scoring 3 goals before the opponent, and a lose condition of conceding 3 goals.

**Controls:** (For games built within CreatorVerse) Player controls will be customizable by the game creator but will default to common WASD for movement and mouse for camera/action in 3D environments.

**Visual Style:** Bright, friendly, and slightly stylized 3D assets with clear visual cues. Textures will be clean and appealing, suitable for a broad age range. Environments can range from cartoony to more detailed, depending on creator choice from the asset library.

**Concrete Features:**

1.  **Drag-and-Drop Asset Placement:** Users can select 3D models (e.g., soccer balls, goals, field pieces, characters) from a library and drag them directly into their 3D scene.
2.  **Terrain Sculpting Tool:** A simple brush-based interface allows users to raise, lower, and flatten terrain for their game worlds.
3.  **Visual Scripting Blocks:** Users can chain together pre-defined logic blocks (e.g., "When Ball Touches Net, Add Score") to define game rules and interactions without traditional coding.
4.  **Pre-set Game Templates:** Users can start building from templates like "Soccer Match," "Obstacle Course Race," or "Treasure Hunt," which pre-populate common assets and basic mechanics.
5.  **Character Customizer:** A tool allowing users to change the color, basic clothing, and accessories of character models.
6.  **Physics Toggle:** Creators can enable or disable realistic physics for objects (e.g., balls bouncing, characters colliding) with adjustable properties like gravity and friction.
7.  **Simple AI Opponent:** An optional pre-built AI behavior that can be assigned to opponent characters, allowing for basic gameplay against non-player characters.
